# Changelog

## 1.0.0

- Clipboard for .NET MAUI on Android and iOS beyond MAUI `Clipboard`
- `ClipboardPlus.SetTextAsync` / `SetSensitiveTextAsync` with automatic expiration
- URI, image, and file copy / read
- `HasText`, `HasImage`, `HasUri`, `HasFiles` without reading the payload
- `ContentChanged`, `Copied`, and `Expired` events
- Clear sensitive content on app background
- Sample app and unit tests
